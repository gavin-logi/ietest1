# IE数字化（ie-digital）

罗技苏州工厂 IE 数字化项目。由 [logi_barebone](https://github.com/gavin-logi/logi_barebone) 模板派生：Vue 3 + TypeScript 前端，Python 3.12 + Django 5.2 LTS 后端，单镜像部署。

三种运行模式（本地开发、本地容器、AWS ECS）、环境变量与提交约束见 [docs/INIT.md](docs/INIT.md)，派生过程中遇到的问题见 [docs/派生与运行问题记录.md](docs/派生与运行问题记录.md)，协作约定见 [AGENTS.md](AGENTS.md)。
